# 150 : Mitrêve

Emplacement `mitreve`. Type Arcane. Mythique, pas d'évolution. Nom féminin.

**Légende.** Aucune : Mitrêve est une création du jeu. Elle prolonge les croyances sur les papillons de nuit, qu'on disait porteurs d'âmes ou de songes.

**Dans le jeu.** Une petite mite duveteuse qui flotte endormie, les ailes marquées de croissants de lune. Elle apparaît dans la Bibliothèque Engloutie une fois les 149 autres espèces capturées. Elle est différente de Follumine : pas de lanterne ni de lumière, mais un rêve. Éléments signature : croissants de lune sur les ailes, antennes en plumes, yeux fermés, étoiles.
