# Captures d'écran

Les fichiers PNG de ce dossier servent au README principal.

| Fichier | Contenu |
|---|---|
| `title.png` | Écran titre |
| `town.png` | Carte ou ville |
| `menu.png` | Menu START |
| `battle.png` | Interface de combat |

Régénérer les captures avec :

```powershell
npm run screenshots
```

L’outil est défini dans `tools/capture-screenshots.js`.
