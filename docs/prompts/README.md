# Prompts d'implémentation

Les prompts sont séparés en deux phases. Chaque phase peut être reprise indépendamment, mais les fichiers de la phase 1 doivent être terminés avant ceux de la phase 2.

| Phase | Contenu | Index |
|---|---|---|
| [phase-1](phase-1/) | Socle Electron, graphismes, données, cartes, combat, interfaces, monde, sauvegarde | [README](phase-1/README.md) |
| [phase-2](phase-2/) | Villes et PNJ, portraits, attaques, musiques | [Voir les quatre prompts](phase-2/prompt-1-villes-et-pnj.md) |

## Ordre recommandé

1. Lire [docs/design/GAME_DESIGN.md](../design/GAME_DESIGN.md) et [docs/technical/ARCHITECTURE.md](../technical/ARCHITECTURE.md).
2. Exécuter les prompts de la phase 1 dans l'ordre 01 à 13.
3. Exécuter les prompts de la phase 2 selon les besoins : PNJ, portraits, attaques et musiques.
4. Mettre à jour [docs/progress/PROGRESS.md](../progress/PROGRESS.md) après chaque étape.
