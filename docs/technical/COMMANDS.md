# Commandes npm

| Commande | Rôle |
|---|---|
| `npm start` | Lance le jeu |
| `npm run dev` | Lance avec DevTools et menu debug |
| `npm test` | Tests unitaires |
| `npm run atlas` | Régénère `assets/atlas/*.png` et `*.json` |
| `npm run validate` | Valide les données |
| `npm run dist` | Construit les installeurs de la plateforme courante |
| `npm run icon` | Régénère les icônes de l'application |
| `npm run screenshots` | Régénère les captures du README |
| `npm run perf` | Mesure les performances |
| `npm run creature-design -- <module>` | Génère une source de bestiole |
| `npm run planche -- 001-009` | Génère une planche face, dos et icône |
| `npm run check-text` | Vérifie que les textes tiennent dans leur fenêtre |
